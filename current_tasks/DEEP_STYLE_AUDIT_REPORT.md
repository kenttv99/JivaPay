## 🏗️ Финальная архитектура стилей

### Структура UI-kit
```
frontend/ui-kit/
├── styles/
│   ├── variables.css      # Базовые CSS переменные
│   └── themes/
│       ├── light.css      # Светлая тема
│       └── dark.css       # Темная тема
├── components/            # React компоненты
└── index.ts              # Экспорты + импорт переменных
```

### Структура каждого приложения
```
{app}/src/app/
└── globals.css           # Только импорты:
                         # - @import '@jivapay/ui-kit/styles/variables.css'
                         # - @import '@jivapay/ui-kit/styles/themes/{theme}.css'
                         # - @import "tailwindcss"
```

### Tailwind конфигурация
```typescript
// tailwind.config.base.ts - единая база для всех приложений
colors: {
  primary: 'var(--color-primary)',
  secondary: 'var(--color-secondary)',
  accent: 'var(--color-accent)',
  success: 'var(--color-success)',
  error: 'var(--color-error)',
  // ... все через CSS переменные
}
```
