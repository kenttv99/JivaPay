## ⚠️ ВАЖНО: Архитектурное разделение приложений (декабрь 2024)

### Два типа архитектуры в экосистеме JivaPay:

**1. Административные приложения (2 приложения):**
- `admin_app` - полная административная панель
- `support_app` - панель поддержки пользователей

**Характеристики:**
- ✅ Используют общие компоненты из `@jivapay/shared-pages`
- ✅ Используют общие компоненты из `@jivapay/ui-kit`
- ✅ Общие переводы через `@jivapay/i18n`
- ✅ Единая дизайн-система и пользовательский опыт

**2. Специализированные приложения (3 приложения):**
- `teamlead_app` - управление командой трейдеров
- `trader_app` - работа с реквизитами и ордерами  
- `merchant_app` - управление магазинами и платежами

**Характеристики:**
- ❌ НЕ используют `@jivapay/shared-pages` (кастомные интерфейсы)
- ✅ Могут использовать базовые стили из `@jivapay/ui-kit` (CSS переменные)
- ✅ Создают ЛОКАЛЬНЫЕ компоненты с уникальным UX для каждой роли
- ✅ Локальные переводы без зависимости от общих пакетов
